# StatTile

A `surface-2` tile with a caption, one big number and a unit; tints its number `bad` or `warn` when the count needs attention.

- Markup: `<div class="stat bad"><small>Stopped services</small><b>1</b><span>on servers</span></div>`, four across in `cards4`.
- The topbar's live counters are the compact form: `<div class="stats"><div><small>Shift time</small><b>09:42</b></div>…</div>`, with `pen` turning Penalties `bad`.
