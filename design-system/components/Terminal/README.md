# Terminal

The in-game command prompt: mono text on the fixed `console-bg`, a `console-prompt` prefix and an inline input.

- Markup: `<div class="terminal"><pre>…</pre><div class="term-line"><span class="pr">C:\&gt;</span><input></div></div>`.
- Fixed dark in both themes. Output is plain text; the landing page's `snip term` variant adds `ok` and `err` colours.
