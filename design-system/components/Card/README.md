# Card

The base container: `surface`, 1px `border`, `radius` (10px) and the resting `shadow`. `pad` adds 16px.

- Markup: `<div class="card pad">…</div>`. Tables and split panes go in a card without `pad`.
- `feature` is the flatter start-screen variant (no shadow). `coach-cta` adds the 4px `accent` edge for the one tutoring call-to-action.
- Don't nest cards.
