# NavItem

A sidebar row: a 19px line icon, a label and an optional count badge. Resting `muted`, hover `surface-2`, active `accent` on `accent-soft`.

- Markup: `<button class="nav on">{icon}<span>Ticket Queue</span><em>4</em></button>`; `em.warn` turns the count `bad` (server alerts).
- Under 1180px the label and count hide and the sidebar becomes a 64px icon rail.
