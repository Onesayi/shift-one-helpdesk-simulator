# ChannelTag

A tiny uppercase tag after a ticket ID that says how the ticket came in and the state of its call.

- Markup: `<span class="chan c-phone">Call</span>`.
- Variants: `c-phone` (accent), `c-live` (on call, good), `c-hold` (on hold or callback due, warn), `c-vm` (voicemail, warn), `c-late` (callback overdue, bad), `c-alert` (monitoring alert), `c-carry` (carried over). Plain `chan` is neutral (Email, Vendor).
