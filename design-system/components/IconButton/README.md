# IconButton

A 34px square bordered button for a single glyph in the topbar: the theme toggle (☾ / ☀) and the ringtone toggle (🔔 / 🔕).

- Markup: `<button class="icon-btn" title="Toggle light/dark">☾</button>`. Always give it a `title`.
- Use only in the topbar; elsewhere use `Button` with a label.
