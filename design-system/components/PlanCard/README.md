# PlanCard

A pricing plan: name, one-line blurb, price, a ✓ feature list and a full-width CTA. The recommended plan gets a 2px `accent` border and a "Most popular" ribbon.

- Markup: `<div class="plans"><div class="plan hl"><span class="ribbon">Most popular</span><h3>…</h3><p class="muted">…</p><div class="price"><b>R450</b><span>per 60-min session</span></div><ul><li>…</li></ul><a class="btn primary lg block">…</a></div></div>`.
- Prices are in rand (R). Four across; two under 860px; one under 520px.
