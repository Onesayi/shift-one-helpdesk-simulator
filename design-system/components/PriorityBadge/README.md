# PriorityBadge

An uppercase 10.5px/800 tag for ticket priority, coloured by the priority ramp on its soft tint.

- Markup: `<span class="prio p-critical">Critical</span>`; also `p-high`, `p-medium`, `p-low`, and `p-new` (untriaged, coordinator mode).
- Colours: `crit` on `bad-soft`, `high` and `med` on `warn-soft`, `low` on `good-soft`.
- Every pair reaches 4.5:1 in both themes.
