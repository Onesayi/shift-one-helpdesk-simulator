# Modal

A centred `surface` dialog over the `scrim`, max 460px, radius-12, `shadow-modal`. Used for identity verification, confirmations and KB articles.

- Markup: `<div class="overlay"><div class="modal"><h3>…</h3><div class="modal-body">…</div><div class="row end">buttons</div></div></div>`.
- Primary action last on the right. `spinner` shows while a simulated action runs.
