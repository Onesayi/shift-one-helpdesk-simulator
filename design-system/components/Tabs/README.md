# Tabs

An underline tab strip for the sub-views of one object (a device's Overview, Apps, Services, Settings, Command prompt).

- Markup: `<div class="tabs"><button class="on">Overview</button>…</div><div class="tab-body">…</div>`.
- Active tab: `accent` text and a 2px `accent` underline; others `muted`. The strip scrolls sideways on narrow screens.
