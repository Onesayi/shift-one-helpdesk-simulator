# Topbar

The 56px app header: the mark and name, the shift name, live counters, the on-call pill and the global actions.

- Markup: `<header id="topbar"><div class="brand">{logo}<span>Shift One</span><small>Day One · Timed</small></div><div class="stats">…</div><div class="grow"></div>…</header>`.
- On start screens the topbar carries the 4px priority stripe (`crit` 40%, `high` 30%, `med` 20%, `low` 10%) and `top-links`.
