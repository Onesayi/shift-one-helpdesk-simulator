# Field

Label-over-control form rows: text inputs, selects, textareas and checkboxes share one bordered `surface` look and an `accent` focus state.

- Markup: `<label class="field"><span>Label</span><input id="…"></label>`; checkboxes use `<label class="check"><input type="checkbox"> Text</label>`.
- Focus: `accent` border plus the `focus-ring` halo.
- `select.sm` is the compact inline select. Field labels are 12px/600 `muted`.
