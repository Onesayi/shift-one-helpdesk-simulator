# Toast

A short dark confirmation that floats at the bottom centre and fades out, with a 4px tone edge.

- Markup: `<div id="toasts"><div class="toast good">…</div></div>`; tones: default (`toast-info`), `good`, `bad`, `info` (amber, `toast-warn`). Add `out` to fade.
- Always dark in both themes (`toast-bg`, white text). Past tense, one line: "Password reset. User must change it at next sign-in."
