# KbLink

An inline text action in `accent` with an optional leading icon: links to a knowledge-base article, the tutoring page, or another desk.

- Markup: `<button class="kb-link">{icon}SOP: Account lockout</button>` or `<a class="kb-link" href="…">`.
- Forward links end with →. Underlines appear on hover for `<a>`.
