# Icons

24px line icons from the sidebar, stroke 1.8, round caps and joins, no fill. Files are drawn in `muted` (#647184) so they read on both themes in `<img>`; in the product they are inline SVG with `stroke: currentColor` (muted at rest, `accent` when active).

- `queue.svg`: Ticket Queue (help desk) and Board (coordinator).
- `directory.svg`: Directory and Team.
- `remote-desktop.svg`: Remote Desktop; also the device link in the ticket panel.
- `server-room.svg`: Server Room.
- `knowledge-base.svg`: Knowledge Base and Playbook; also KB links.
- `phone.svg`: calls everywhere (ringer, call bar, on-call pill).
- `dispatch.svg`: the coordinator's Dispatch schedule and appointment lines.
- `clients.svg`: the coordinator's Clients.
