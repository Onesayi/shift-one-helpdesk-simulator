# Logos

- `help-desk-mark.svg`: the Help Desk mark, a monitor with a command prompt. Stroked outline, ink `accent` (#2459d6) at 2.2 on a 32px grid. Inline it and set `stroke: currentColor` to recolour; in `<img>` it stays #2459d6.
- `coordinator-mark.svg`: the Service Coordinator mark, a calendar with booked slots. Same stroke and ink.
- `help-desk-app-icon.svg`: the favicon and app icon, the prompt glyph in white on an #2459d6 square with 7px corners.
- `coordinator-app-icon.svg`: the Coordinator favicon, the calendar glyph in white on the same square.

The topbar sets the mark at 26px beside "Shift One" in 16px bold. There is no separate wordmark: set the name in type.
